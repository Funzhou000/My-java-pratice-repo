# Java 学习练习仓库

这是一个用于学习 Java 编程的练习仓库，涵盖从基础 OOP 到高级特性的各种练习。

## 📁 目录结构

```
.
├── 01-oop-basics/           # OOP 基础
│   ├── inheritance/         # 继承
│   ├── polymorphism/        # 多态
│   ├── abstraction/         # 抽象类
│   ├── interface/           # 接口
│   ├── inner-class/         # 内部类
│   ├── anonymous-class/     # 匿名内部类
│   └── adapter-pattern/     # 适配器模式
│
├── 02-data-structures/      # 数据结构
│   ├── array/               # 数组
│   ├── linkedlist/          # 链表
│   └── custom-collections/  # 自定义集合
│
├── 03-algorithms/           # 算法
│   ├── sorting/             # 排序算法
│   ├── searching/           # 搜索算法
│   ├── recursion/           # 递归问题
│   └── leetcode/            # LeetCode 题解
│
├── 04-java-core/            # Java 核心特性
│   ├── collections/         # 集合框架
│   ├── generics/            # 泛型
│   ├── lambda/              # Lambda 表达式
│   ├── stream/              # Stream API
│   ├── exception/           # 异常处理
│   └── method-reference/    # 方法引用
│
├── 05-io/                   # 输入输出
│   ├── file-operations/     # 文件操作
│   ├── byte-stream/         # 字节流
│   ├── char-stream/         # 字符流
│   └── buffered-stream/     # 缓冲流
│
└── 06-projects/             # 项目实战
    ├── poker-game/          # 扑克牌游戏
    ├── puzzle-game/         # 拼图游戏
    └── landlord-game/       # 斗地主游戏
```

## 🚀 快速开始

1. 克隆仓库
```bash
git clone <repository-url>
```

2. 使用 IDE 打开项目（推荐 IntelliJ IDEA 或 VS Code）

3. 选择感兴趣的模块开始学习

## 📚 学习路线

1. **OOP 基础** - 面向对象编程核心概念
2. **数据结构** - 常用数据结构实现
3. **算法** - 排序、搜索及经典算法问题
4. **Java 核心** - 集合、泛型、Lambda 等高级特性
5. **IO 操作** - 文件读写和流处理
6. **项目实战** - 综合应用所学知识
